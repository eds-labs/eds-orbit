## Interpretation and deliberate boundaries

A05/K08 require genuine paid model acceptance and remain blocked by missing application credentials and an approved test budget. A14/A17 require explicitly authorized real provider tests. H07/H08 require an off-host destination/key-escrow process and an independent alarm destination. Those prerequisites are external. Container boot, UI and scheduling validation are complete; their test evidence does not substitute for these live prerequisites.

No ANN, live-accepted image generation, arbitrary CMS endpoint, mail engine, paid-ad account control, private community scraping or automatic Postiz group deletion is claimed. The optional GPT Image 2.5 adapter exists locally, but genuine provider availability, usage and cost remain `BLOCKED_EXTERNAL` until a separately approved bounded run. Postiz local scheduling uses due-time `now` handoff and displays unsupported remote cancellation honestly.
