# Privacy Checklist

## Prüffragen

- Werden personenbezogene Daten verarbeitet?
- Welche Daten genau?
- Warum sind sie nötig?
- Werden Daten an Dritte gesendet?
- Gibt es Tracking?
- Gibt es Export/Löschung?
- Gibt es Aufbewahrungsfristen?
- Werden Daten in AI-Prompts oder Logs verarbeitet?

## Codex-Regel

Bei neuen Userdaten oder Tracking immer Privacy Notes ausgeben.
