# Git Workflow

## Vor Änderungen

- Status prüfen.
- Bestehende uncommitted Änderungen respektieren.
- Keine fremden Änderungen überschreiben.

## Während der Arbeit

- Logisch zusammengehörige Änderungen gruppieren.
- Generierte Dateien und Lockfiles bewusst prüfen.
- Keine Secrets committen.

## PR-Erwartung

- Problem, Lösung und Verifikation beschreiben.
- Breaking Changes sichtbar machen.
- Screenshots für relevante UI-Änderungen ergänzen.
- Migrations und Rollback notieren.
