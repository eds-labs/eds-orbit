# Workflow: Release

## Prüfen

- Changelog aktualisiert?
- Version korrekt?
- Tests/Build grün?
- Migrations bewertet?
- Feature Flags dokumentiert?
- Breaking Changes sichtbar?
- Monitoring/Alerts vorhanden?
- Rollback möglich?

## Output

- Release Summary
- Verifikation
- Risiken
- Rollback-Hinweise
- Post-Release Checks
