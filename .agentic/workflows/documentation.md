# Workflow: Documentation

## Schritte

1. Zielgruppe klären: Developer, User, Operator, Reviewer.
2. Betroffene Dokumente finden.
3. Konkrete Beispiele ergänzen.
4. Veraltete Aussagen entfernen.
5. Links/Commands prüfen, soweit möglich.

## Output

- Aktualisierte Dokumente
- Was wurde präzisiert?
- Offene Doku-Lücken
