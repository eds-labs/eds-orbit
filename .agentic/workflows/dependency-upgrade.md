# Workflow: Dependency Upgrade

## Schritte

1. Aktuelle Nutzung der Dependency suchen.
2. Changelog/Migration Notes prüfen, falls verfügbar.
3. Breaking Changes identifizieren.
4. Upgrade in kleinem Schritt durchführen.
5. Tests/Build ausführen.
6. Falls Risko hoch: Rollback-Plan notieren.

## Output

- Version vorher/nachher
- Breaking Changes
- Code-Anpassungen
- Verifikation
- Risiken
