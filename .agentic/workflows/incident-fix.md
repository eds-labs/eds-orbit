# Workflow: Incident Fix

## Priorität

Stabilisierung vor Perfektion.

## Schritte

1. Auswirkung und Scope beschreiben.
2. Sicheren minimalen Fix planen.
3. Keine unnötigen Umbauten.
4. Verifikation und Smoke Test.
5. Rollback/Hotfix-Pfad nennen.
6. Follow-up für langfristige Lösung dokumentieren.

## Output

- Impact
- Root Cause, soweit bekannt
- Fix
- Verifikation
- Follow-up Items
