# Workflow: Project / Task Intake

## Ziel

Aufgabe und Projektkontext sauber erfassen, bevor Code geändert wird.

## Schritte

1. `AGENTS.md` und `.agentic/project-profile.yaml` lesen.
2. Projektstruktur grob erfassen.
3. Anwendungstyp bestimmen.
4. Passenden Workflow wählen.
5. Akzeptanzkriterien ableiten.
6. Risiken, No-Gos und Tests notieren.

## Output

- Ziel
- Anwendungstyp
- Workflow
- Akzeptanzkriterien
- Betroffene Bereiche
- Risiken
- Test-/Verifikationsplan
