# Workflow: Refactor

Refactoring darf Verhalten nicht ändern.

## Pflicht

- Vorher bestehende Tests prüfen.
- Falls keine Tests vorhanden: Characterization Tests ergänzen.
- Kleine Schritte.
- Nach jedem größeren Schritt testen.
- Keine Feature-Änderungen beimischen.

## Output

- Was wurde strukturell verbessert?
- Warum ist Verhalten gleich geblieben?
- Welche Tests sichern das ab?
- Welche Risiken bleiben?
