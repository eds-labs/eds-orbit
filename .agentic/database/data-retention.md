# Data Retention Policy

## Leitfragen

- Welche Daten werden gespeichert?
- Warum werden sie gespeichert?
- Wie lange werden sie benötigt?
- Wer darf sie löschen?
- Gibt es Exportpflichten?
- Gibt es gesetzliche Aufbewahrungspflichten?

## Standard

- So wenig wie möglich speichern.
- Sensible Daten minimieren.
- Löschkonzept vorsehen.
- Audit Logs getrennt betrachten.
- Backups in Löschkonzept einbeziehen.

## Codex-Regel

Neue Features mit Userdaten brauchen eine kurze Data-Retention-Notiz, mindestens bei High Risk.
