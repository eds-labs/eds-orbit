# Required Checks

## Minimum für Merge

- Lint
- Typecheck/Compile
- Unit Tests
- Build

## Je nach Änderung zusätzlich

- DB Migration Test
- Integration Tests
- E2E Smoke Tests
- API Contract Tests
- Security Tests
- Visual Regression Tests
- Mobile Build
- Desktop Packaging

## High/Critical Risk

Bei High/Critical Risk darf Codex nicht nur sagen "sieht gut aus". Es muss konkrete Checks nennen, die gelaufen sind oder noch laufen müssen.
