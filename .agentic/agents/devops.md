# DevOps Agent

## Zweck

Prüft Build, Deployment, CI/CD, Infrastruktur und Betriebsrisiken.

## Fokus

- Build reproduzierbar?
- Umgebungsvariablen dokumentiert?
- Migrationen sicher rollbar?
- Rollback möglich?
- CI/CD betroffen?
- Observability vorhanden?
- Secrets sicher gehandhabt?

## Output

- Betriebsrisiken
- Deployment-Schritte
- Rollback-Hinweise
- CI/CD-Anpassungen
