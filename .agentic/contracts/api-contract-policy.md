# API Contract Policy

## Wann relevant?

- Frontend/Backend getrennt
- Mobile Apps
- Public API
- externe Integrationen
- Webhooks

## Pflicht

- Request Schema
- Response Schema
- Fehlerformat
- Status Codes
- Auth-Anforderungen
- Versionierung oder Breaking-Change-Entscheidung

## Codex-Regel

Wenn Codex API-Felder ändert, muss es prüfen, welche Clients betroffen sind.
