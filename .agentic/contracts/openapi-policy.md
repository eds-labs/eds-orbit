# OpenAPI Policy

## Geeignet für

- Public APIs
- Enterprise Integrationen
- API Clients in mehreren Sprachen
- dokumentationspflichtige Schnittstellen

## Regeln

- Schema aktuell halten
- Breaking Changes markieren
- Error Responses dokumentieren
- Auth-Schemes dokumentieren
- Beispiele ohne echte Daten

## Tests

- Contract Tests gegen OpenAPI
- Client Generation aktualisieren
- Backward Compatibility prüfen
