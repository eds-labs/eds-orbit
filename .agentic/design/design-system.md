# Design System Policy

## Ziel

Codex soll UI nicht jedes Mal neu erfinden.

## Regeln

- Bestehende Komponenten wiederverwenden.
- Neue Basiskomponenten nur bei wiederholtem Bedarf.
- Design Tokens nutzen.
- Keine zweite UI-Library ohne ADR.
- Komponenten mit klaren Varianten statt ad-hoc Klassen.

## Pflicht bei neuen Screens

- Loading State
- Empty State
- Error State
- Disabled State
- Responsive Verhalten
- Accessibility Basics
