# Accessibility Policy

## Minimum

- semantisches HTML bzw. native UI-Elemente
- sichtbarer Fokus
- Tastaturbedienung
- sinnvolle Labels
- ausreichende Kontraste
- Fehlerhinweise für Formulare
- keine rein farbliche Information

## Prüffragen

- Kann der Flow ohne Maus genutzt werden?
- Sind Inputs beschriftet?
- Werden Fehler verständlich genannt?
- Sind Dialoge/Modals korrekt fokussiert?
- Haben Icons ohne Text einen accessible name?
