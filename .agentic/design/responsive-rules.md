# Responsive Rules

## Minimum

- Mobile Breite prüfen
- Tablet oder mittlere Breite prüfen, falls relevant
- Desktop Breite prüfen
- Navigation auf kleinen Screens nutzbar
- Tabellen/Listen auf kleinen Screens lesbar
- Touch-Ziele groß genug

## Codex-Regel

Neue UI-Features brauchen eine kurze Aussage zum Mobile-Verhalten.
