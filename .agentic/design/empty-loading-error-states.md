# Empty, Loading and Error States

## Jede datengetriebene UI braucht

- Loading State
- Empty State
- Error State
- Success/Updated State, falls passend
- Disabled State bei Aktionen

## Beispiele

Empty:
- Warum ist hier nichts?
- Was kann der Nutzer als nächstes tun?

Error:
- Was ist fehlgeschlagen?
- Kann erneut versucht werden?
- Gibt es Support/Details?

Loading:
- Skeleton oder Spinner passend zur Dauer
- keine Layout-Sprünge, wenn vermeidbar
