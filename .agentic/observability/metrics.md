# Metrics Policy

## Technische Metriken

- Request Rate
- Error Rate
- Latency
- Queue Length
- Job Failures
- DB Connection Errors
- Deployment Failures

## Produktmetriken

- Aktivierung
- Conversion
- Retention
- Feature Usage

## Datenschutz

Produktmetriken dürfen keine unnötigen personenbezogenen Daten enthalten. Tracking braucht je nach Projekt Datenschutz- und Consent-Prüfung.

## Codex-Regel

Bei neuen kritischen Flows prüfen, ob Erfolg und Fehler messbar sind.
