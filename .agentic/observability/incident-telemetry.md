# Incident Telemetry

## Bei Incidents sammeln

- Zeitfenster
- betroffene Version/Deployment
- betroffene Nutzer/Tenants
- Fehlerrate
- Logs mit Correlation IDs
- kürzliche Änderungen
- externe Provider-Status

## Nach Incident

- Root Cause
- Detection Gap
- Prevention
- Tests ergänzt?
- Runbook aktualisiert?
- Alert angepasst?
