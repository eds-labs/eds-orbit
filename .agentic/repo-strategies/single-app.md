# Repo Strategy: Single App

## Geeignet für

- MVPs
- kleine Webapps
- einzelne Mobile/Desktop App

## Struktur

```txt
src/
tests/
docs/
.agentic/
```

## Vorteil

Einfach, schnell, wenig Tooling.

## Wechsel zu Monorepo prüfen bei

- mehrere Apps
- shared UI/API types
- eigenständiges Backend
- Mobile + Web
