# App Profile: Web Frontend

## Prioritäten

- UX-Konsistenz
- Accessibility
- Responsiveness
- Performance
- Komponenten-Wiederverwendung
- klare State-Grenzen

## Immer prüfen

- Loading State
- Empty State
- Error State
- Disabled State
- Mobile Layout
- Tastaturbedienung
- Screenreader-Relevanz
- Formularvalidierung
- Client/Server-State-Trennung

## Tests

- Komponenten-Tests für Logik.
- E2E für kritische User Flows.
- Keine unnötigen Snapshot-Tests.

## Häufige Risiken

- Doppelte Business-Logik im Frontend.
- Unklare Fehlerbehandlung.
- Accessibility-Regressions.
- Unbounded Client Fetches.
