# AI Memory Policy

## Regeln

- Keine Secrets speichern.
- Keine sensiblen personenbezogenen Daten ohne Zweck speichern.
- Memory muss korrigierbar sein.
- Projektregeln gehören in Dateien, nicht nur in flüchtigen Chat-Kontext.
- Gelerntes klar von Entscheidungen trennen.

## Codex-Regel

Wiederverwendbare technische Erkenntnisse in `.agentic/memory/` dokumentieren, aber keine privaten Daten aufnehmen.
