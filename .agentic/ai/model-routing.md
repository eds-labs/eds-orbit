# AI Model Routing

## Ziel

Kosten, Qualität und Risiko bewusst balancieren.

## Beispiele

- einfache Klassifikation: kleines/günstiges Modell
- komplexe Planung: starkes Reasoning-Modell
- Code Review/Security: starkes Modell
- Tool-Ausführung: Modell + Guardrails + Approval

## Regeln

- kritische Entscheidungen nicht nur über günstiges Modell treffen
- Fallback definieren
- Kostenlimit setzen
- Outputs validieren
