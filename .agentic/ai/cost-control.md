# AI Cost Control

## Regeln

- Tokenlimits setzen
- unnötigen Kontext vermeiden
- Caching prüfen
- Tool Calls begrenzen
- Batch vs Realtime bewusst wählen
- Logging-Kosten beachten
- Eval-Kosten budgetieren

## Codex-Regel

Neue AI-Features brauchen eine Kostenabschätzung auf qualitativer Ebene: low/medium/high und Kostentreiber.
