# Dependency Update Policy

## Updates

- Patch Updates: meist niedriges Risiko
- Minor Updates: Changelog prüfen
- Major Updates: Breaking Changes und Migration Guide prüfen
- Security Updates: priorisieren, aber testen

## Pflicht bei Major Updates

- betroffene APIs suchen
- Tests ausführen
- Changelog/Migration Notes notieren
- Rollback einfach halten

## Codex-Regel

Keine großen Dependency-Upgrades mit Feature-Arbeit vermischen.
