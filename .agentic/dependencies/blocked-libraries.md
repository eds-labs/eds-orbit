# Blocked Libraries

Trage projektspezifische No-Gos ein.

## Beispiele

- unmaintained Pakete
- Libraries mit inkompatibler Lizenz
- zweite UI-Library neben bestehendem Design-System
- Pakete, die Secrets an Dritte senden
- schwergewichtige Dependencies für triviale Funktionen

## Codex-Regel

Wenn eine Library hier auftaucht, darf Codex sie nicht hinzufügen, ohne eine ADR und explizite Freigabe vorzuschlagen.
