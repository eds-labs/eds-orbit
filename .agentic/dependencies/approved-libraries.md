# Approved Libraries

Passe diese Liste je Projekt an. Beispiele:

## TypeScript Web

- TypeScript
- Zod oder Valibot für Validation
- TanStack Query für Server State
- React Hook Form für komplexe Forms
- Playwright für E2E
- Vitest für Unit Tests

## Python

- pytest
- ruff
- pydantic
- typer für CLI

## Datenbank

- Prisma oder Drizzle, nicht beides ohne Begründung
- Postgres als Default für relationale Produktionsdaten
