# Deployment Preset: Mobile App Stores

## Geeignet für

- iOS App Store
- Google Play Store
- Expo EAS oder native Pipelines

## Pflichtchecks

- App Signing/Certificates
- Bundle Identifier / Package Name
- Privacy Labels / Data Safety
- Push Notification Certificates
- Store Screenshots und Texte
- Versioning: build number vs app version
- Rollout-Strategie
- Crash Reporting

## Release Notes

Jede mobile Veröffentlichung braucht:

- Nutzerrelevante Änderungen
- bekannte Einschränkungen
- Migrationshinweise
- Feature Flags oder Remote Config bei riskanten Features
