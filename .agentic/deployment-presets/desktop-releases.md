# Deployment Preset: Desktop Releases

## Geeignet für

- Tauri
- Electron
- Avalonia
- native Desktop-Apps

## Pflichtchecks

- Code Signing
- Notarization für macOS
- Installer/Updater testen
- Auto-Update Channel: stable/beta
- Rollback-Version verfügbar
- lokale Datenmigration testen
- Crash Reporting optional

## Plattformen

- macOS: Signierung, Notarization, Universal Binary prüfen
- Windows: Installer, SmartScreen, Signierung prüfen
- Linux: AppImage/deb/rpm oder Paketmanager-Strategie klären
