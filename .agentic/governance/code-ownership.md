# Code Ownership

## Ziel

Kritische Bereiche haben klare Review-Erwartungen.

## Beispiele für Owner-Bereiche

- Auth/Security
- Billing
- Datenbankmigrationen
- Infrastruktur
- Mobile Release
- Design System
- AI Agent Tools

## Codex-Regel

Wenn eine Änderung einen Owner-Bereich betrifft, muss Codex dies im Handoff nennen.
