# Escalation Rules

## Eskalieren bei

- unklarem Production-Zustand
- fehlendem Backup bei DB-Risiko
- widersprüchlichen Anforderungen
- möglichem Datenleck
- Security Boundary unklar
- Provider-Kosten unklar
- rechtlichen/Privacy-Fragen

## Output

Codex soll nicht blockieren, sondern transparent markieren:

```md
Escalation Needed:
Reason:
Safe Next Step:
```
