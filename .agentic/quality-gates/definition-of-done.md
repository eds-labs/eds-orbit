# Definition of Done

Eine Aufgabe ist nur fertig, wenn:

1. Ziel erfüllt.
2. Akzeptanzkriterien erfüllt oder Abweichungen begründet.
3. Änderung minimal und nachvollziehbar.
4. Relevante Tests ergänzt oder bewusst begründet weggelassen.
5. Lint/Typecheck/Build/Tests ausgeführt oder Einschränkung genannt.
6. Keine offensichtlichen Security-Probleme.
7. Keine unnötigen neuen Dependencies.
8. Dokumentation aktualisiert, falls API, Config, Setup oder Verhalten betroffen ist.
9. Abschlusszusammenfassung vorhanden.

## Abschlussformat

```md
## Summary
- ...

## Changed Files
- `path`: ...

## Verification
- [x] ...
- [ ] Nicht ausgeführt: ... Grund: ...

## Risks / Notes
- ...

## Follow-ups
- ...
```
