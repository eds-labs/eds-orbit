# Accessibility Checklist

- [ ] Semantisches HTML oder passende Rollen
- [ ] Tastaturbedienung möglich
- [ ] Fokuszustände sichtbar
- [ ] Labels für Formulare
- [ ] Fehler für Screenreader erreichbar
- [ ] Kontrast ausreichend
- [ ] Keine reine Farbkommunikation
- [ ] Loading/Disabled States verständlich
- [ ] Mobile und Zoom geprüft, wenn relevant
