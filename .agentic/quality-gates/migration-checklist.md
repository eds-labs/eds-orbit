# Migration Checklist

- [ ] Vorwärtskompatibilität geprüft
- [ ] Rückwärtskompatibilität geprüft oder bewusst ausgeschlossen
- [ ] Datenverlust-Risiko bewertet
- [ ] Backfill-Plan vorhanden, falls nötig
- [ ] Rollback-/Recovery-Plan vorhanden
- [ ] Migrationen nicht nach Deployment verändert
- [ ] Tests mit realistischer Datenmenge erwogen
- [ ] Deployment-Reihenfolge dokumentiert
