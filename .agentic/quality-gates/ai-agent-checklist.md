# AI Agent Checklist

- [ ] Tool-Berechtigungen nach Least Privilege
- [ ] Tool-Inputs validiert
- [ ] Tool-Outputs validiert
- [ ] Riskante Aktionen approval-gated
- [ ] Prompt-Injection-Fälle bedacht
- [ ] Keine unnötigen sensiblen Daten im Prompt
- [ ] Tracing/Logging ohne Secrets
- [ ] Kosten-/Token-Grenzen bedacht
- [ ] Evals oder Simulationen für typische Aufgaben
- [ ] Negativtests für Missbrauchsfälle
