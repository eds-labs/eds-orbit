# Test Data Policy

## Regeln

- keine echten Kundendaten
- keine echten E-Mail-Adressen außer reservierten Beispielen
- deterministische Seeds
- Testuser klar markieren
- sensible Fälle synthetisch erzeugen

## Codex-Regel

Neue Tests dürfen keine realistischen Secrets oder echten personenbezogenen Daten enthalten.
