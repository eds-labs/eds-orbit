# Quotas

## Typische Quotas

- Speicherplatz
- Teammitglieder
- Projekte
- API Calls
- AI Credits/Tokens
- Exporte
- Background Jobs

## Regeln

- Quotas serverseitig erzwingen
- UI darf Quotas anzeigen, aber nicht allein durchsetzen
- Race Conditions bei Verbrauch beachten
- Abrechnung/Subscription-Plan berücksichtigen
