# Runbooks

## Wann Runbooks nötig sind

- Production Deployments
- Incidents
- DB Restore
- Payment Provider Probleme
- Queue Backlog
- Auth Provider Ausfall
- Mobile Release Rollback

## Runbook Template

```md
# Runbook: <Name>

## Symptome
## Diagnose
## Sofortmaßnahmen
## Rollback/Recovery
## Kommunikation
## Nachbereitung
```
